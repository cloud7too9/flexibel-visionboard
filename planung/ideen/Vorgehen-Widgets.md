# Vorgehen: Widgets der Companion PWA

Stand: 01.10.2026

## Reihenfolge

1. **Inhalte sammeln** über alle Bereiche (erledigt, siehe Widget-Inhalte)
2. **Theme pro Bereich zuordnen** (teilweise erledigt, siehe Bereichs-Themes)
3. **Vereinheitlichen:** Inhalte erkennen, die eigentlich ein Widget in verschiedenen Größen sind, und zusammenfassen
4. **Größen festlegen** im 32-Spalten-Raster

## Beobachtung für Schritt 3

Mehrere Bereiche folgen dem Muster „ein Einzelstück aus einer Sammlung als Widget“:

- Einzelkoordinate / Koordinatensammlung (Karte)
- Einzelobjekt / Listen (Sammelobjekte)
- Einzelner Eintrag (Handbuch)
- Einzelner Bauplan (Baupläne)
- Banner mit Bauplan (Banner)
- Rüstungs-Set mit Bauplan (Rüstung)

Kandidat: ein gemeinsamer Widget-Typ „Einzeleintrag“, der sich nur in Inhalt und Bereichs-Theme unterscheidet.
